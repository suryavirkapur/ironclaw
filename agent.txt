current context:
- workspace version is now `0.10.1`
- `ironclawd` api router is now fully wired for:
  `/api/health`, `/api/ready`,
  `/api/channels/telegram/webhook`,
  `/api/channels/whatsapp/webhook`,
  `/api/admin/vms`,
  `/api/admin/keys`,
  `/api/admin/memory`,
  `/api/admin/heartbeat`,
  and scalar docs at `/api/docs`
- webhook endpoints now validate `x-webhook-secret` and route inbound messages
  into guest transport sessions with auth challenge/ack
- heartbeat scheduler now starts with a 30-minute interval and triggers guest
  heartbeat execution through the same isolated transport path
- host-side tool execution for guest tool calls is blocked by policy
  (only `host_plan` is allowed on host)
- host sqlite now stores api keys in `host_api_keys` and admin api returns
  masked values only
- host memory admin list/detail now reads from sqlite memories and writes
  markdown/jsonl snapshots under `data/users/<user>/memory/`
- askama-rendered home page added at `/` with template
  `crates/ironclawd/templates/home.html`
- embedded `/ui` assets now expose an interactive admin dashboard for
  heartbeat, vm management, api keys, and memory inspection
- root `Dockerfile` added for single-binary container deployment

important decisions:
- sqlite is currently accepted for host persistence in this phase
- no orm introduced; all persistence is explicit sql
- host never executes guest-requested shell/file tools
- existing legacy routes were kept; new api routes are merged alongside them
- askama is used for server-rendered static view (`/`), while admin ui remains
  served from embedded static assets at `/ui`

architectural notes:
- guest session setup is centralized via `open_guest_session_transport`
- webhook ingress path uses `route_webhook_message_to_guest` and keeps traffic
  on host/guest transport boundaries
- vm runtime visibility for admin api is backed by in-memory vm registry state
  tracked from vm startup/shutdown points
- heartbeat runtime metrics are tracked in `HeartbeatRuntimeState` and exposed
  by `/api/admin/heartbeat`
